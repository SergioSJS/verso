# Web Pages and HTML

A web page can be a note of yours, with annotations; an `.html` file in the folder opens as a page; and a page can appear in the middle of a note.

---

## A Page Saved as a Note

**New web page…** (in the **New** menu of the `+` button on the left ribbon, or in a folder's menu) asks for the address and creates a note with it. Every note with the `url` property at the top is a page: the tab gets the **Back**, **Forward** and **Reload** bar.

- **Show page** and **Show note** switch between the site and the note's text — your annotations about it.
- The address, in the bar, opens the page in a window of its own.
- The star beside the title adds the page to your bookmarks, like a bookmark.

Open [[Web/jsoncanvas.org]] to see one.

---

## HTML Files

An `.html` file in the folder opens as a page — without running scripts. In the corner of the tab, **Page** and **Source** switch between the page and the code. Open [[Web/Business Card.html]].

---

## A Page Inside a Note

An `<iframe>` embeds a page in the middle of a note; the first time a site appears, Verso asks before loading it. See how in [[06 - Documents and Media#🌐 Web Pages Inside the Note|Documents and Media]].

> [!note] Remote content
> **Settings › General › Load remote content** decides whether web images and site icons load on their own. When it is off, nothing goes out to the network without a click from you.
