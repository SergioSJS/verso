# Running a Table

A **table** is a campaign folder on a UniVerso (Verso on a server of your own, [[23 - Verso on a Server]]): you, the game master, invite the players to it alone, and each note stays **hidden** until you release it. None of this is written in the notes: what is released, which names are secret and who may edit is kept in the server's database, so a synced file, or one opened in Obsidian, is an ordinary note.

Only the folder's owner does this, on a folder of a server or on a folder of this computer **synced** with one ([[23 - Verso on a Server]]): the game master can run the session from the desktop app, with the local folder, while the players use the browser or the Windows app on the server's folder. With no connection (or with sync paused) the table is unavailable and the **Table** panel says so; it comes back by itself when the connection does. On a folder of this computer alone there is no table, and none of this shows.

---

## Make the folder a table

1. With the folder open, the **Table** panel has the **Make this folder a table** button (only for the owner of a server's folder that is not a table yet); after it, **Open the Table window**. When the open folder is already a table, its owner sees a **Table** button beside the folder's name that opens the Table window; players see a **Table · player** chip there that shows what they can do (read the released notes and edit the ones granted to them, as links) and has no settings. It also works with a right click on a folder › **Make this folder a table**, or, for the whole folder, on the list's background › **Make the whole folder a table**. In a folder only on this computer the panel says why there is no table.
2. The **Table** window opens. Every note of the folder, the ones already there and the ones you make later, starts **hidden**, with a padlock in the list.
3. To go back: **Undo table** in the same window, or in the folder's menu. The files never changed.

A game master may have several tables, one folder each.

---

## Invite the players

In the **Table** window, **Invite players › Make link** makes a single-use link, good for 7 days, that gives **reading** of this table and only it: whoever accepts sees the table's folder and nothing above or beside it. **Copy the link** and send it.

Only whoever runs the server invites someone with no account yet; someone who has one comes in through the folder's **Share…** ([[14 - Files and Folders]]).

**Table open** is the door: off, players cannot open the folder ("the table is closed"; whoever is inside leaves) and you always can.

---

## Release bit by bit

- Right-click a note › **Release to the table**. It shows in the players' list, in searches, in the graph, in links and in boards; it syncs to their device.
- **Hide from the table** takes it back (the device is told to let it go).
- On a folder of the table: **Release everything here** and **Hide everything here**. With several notes selected, the same in the selection's menu. In the **Table** window: **Release everything**.

A hidden note does not exist for a player: it is in no list, and asking for it answers as asking for a note that never was. Images and files only show if a **released** note shows them. The `> [!secret]` blocks ([[25 - Dice and Random Tables]]) still hide a piece of a released note.

---

## A link to a note that has not appeared yet

In a released note, `[[Baron]]` to a hidden note reaches the player as **Baron 🔒**: the text, no link, so they know something is there. With an alias, `[[The Baron's Betrayal|a rumour]]` becomes **a rumour 🔒**. An embed `![[Crypt]]` becomes "🔒 (not revealed yet)". The path, a section's title and a `^id` are never sent.

When the name is already a spoiler: right-click the hidden note › **Secret name**, and every link to it becomes ▒▒▒▒, always the same length. A **board** card for a hidden note also arrives as a locked card. Once the note is released, links work for everyone.

---

## Who edits

By default players only read. Right-click a note › **Editable by** picks **nobody**, **the group** (every player edits: the group's note) or **one player** (their sheet). The note is released with the permission, and whoever edits it reads it **whole**, with its secret blocks and links as you wrote them: if there is a secret in it, do not give it to anyone.

Nobody but you renames, deletes or creates notes or files; the server checks this at every door (the window, the editing room, the synced device).

---

## The table's limits

Under **The table's limits**: how many entries the [[31 - The Table|Table]]'s log keeps (1,000 to 200,000; 20,000 at first) and the size of an image on it (1 to 30 MB; 10 at first). Past the log's limit, the oldest that are not pinned go.
